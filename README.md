# yandex-maps-parser
Это мощный инструмент с графическим интерфейсом (GUI) для автоматизированного сбора контактных данных потенциальных B2B-клиентов.   Программа умеет находить лиды из двух основных источников: 1. Яндекс.Карты— сбор локальных бизнесов по городам и нишам. 2. Биржи Фриланса (FL.ru, Kwork)— сбор горячих заказов на разработку сайтов, парсеров и ботов.
