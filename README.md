# LEADNEXUS

**LEADNEXUS** — это мощный инструмент с графическим интерфейсом (GUI) для автоматизированного сбора контактных данных потенциальных B2B-клиентов. 

Программа умеет находить лиды из двух основных источников:
1. **Яндекс.Карты** — сбор локальных бизнесов по городам и нишам.
2. **Биржи Фриланса (FL.ru, Kwork)** — сбор горячих заказов на разработку сайтов, парсеров и ботов.

Интерфейс написан на современном фреймворке **CustomTkinter** (темная тема), а под капотом используется асинхронный парсинг с помощью **Playwright** и **BeautifulSoup4**, что позволяет легко обходить защиты от ботов (например, Cloudflare на Kwork).

---

## 🚀 Основной функционал

### 🗺️ Парсинг Яндекс.Карт
* **Свои города и ниши**: Возможность искать как по предзаданным спискам, так и вводить свои собственные города и ниши через запятую.
* **Умные фильтры**:
  * *Только без сайта*: Идеально для веб-студий (ищет компании, у которых нет сайта в профиле).
  * *Только с телефоном*: Отсеивает компании без контактов.
* **Скрытый браузер**: Возможность запускать парсер в фоновом (headless) режиме, чтобы не мешать работе.
* **Лимиты**: Удобный ползунок для ограничения количества собранных лидов за один проход.

### 💼 Парсинг Бирж Фриланса (FL.ru, Kwork)
* **Анализ заказов**: Автоматический сбор свежих проектов по выбранным категориям.
* **Кастомные ключевые слова**: Поиск только тех заказов, которые содержат ваши ключевые слова (например, `сайт, бот, парсер`).
* **Фильтр бюджета**: Автоматический отсев дешевых заказов (минимальный порог в рублях).

### ⚙️ Общие фичи
* **Экспорт в Excel**: Результаты автоматически формируются в красивую таблицу `.xlsx` с разделением на вкладки (Карты и Фриланс).
* **AI-шаблоны**: Программа сама генерирует готовые шаблоны первых сообщений (офферов) и deeplink-ссылки на WhatsApp и Telegram для быстрого старта диалога.
* **Автосохранение настроек**: Ваш выбор чекбоксов и списки слов сохраняются в `settings.json` и восстанавливаются при следующем запуске.
* **Звуковые уведомления**: Уведомление по завершению работы.

## 🛠️ Установка и запуск (Исходный код)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/leadnexus.git
   cd leadnexus
   ```

2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для Mac/Linux:
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Установите браузеры для Playwright:
   ```bash
   playwright install chromium
   ```

5. Запустите приложение:
   ```bash
   python gui_app.py
   ```

## 📦 Сборка в EXE

Проект можно скомпилировать в один исполняемый файл для Windows с помощью PyInstaller.

```bash
pyinstaller --noconfirm --onefile --windowed --name "LEADNEXUS" --add-data ".venv\Lib\site-packages\playwright\driver;playwright/driver" gui_app.py
```

*(Внимание: пути к `playwright/driver` могут отличаться в зависимости от ОС и менеджера пакетов)*.

## 📂 Структура проекта
* `gui_app.py` — Точка входа, графический интерфейс (CustomTkinter).
* `parsers/` — Модули парсеров (`yandex_maps.py`, `fl_ru.py`, `kwork.py`).
* `exporters/` — Логика выгрузки данных (`excel.py`).
* `utils/` — Вспомогательные утилиты, шаблонизатор сообщений и deeplinks.
* `models.py` — Pydantic модели данных для типизации лидов.
* `config.py` — Глобальные константы и настройки по умолчанию.
